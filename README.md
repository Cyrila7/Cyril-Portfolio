# Cyril Portfolio — Phase 1

Dark-luxury, responsive portfolio built with React, Vite, Framer Motion, and plain CSS.

## Features
- First-visit welcome popup (session-based, replayable)
- Recruiter Mode toggle and quick navigation
- Featured PathPilot and CyrilHQ cards
- Interactive CyrilHQ pipeline walkthrough
- Project details, skills, experience, contact links
- Responsive navigation and reduced-motion support

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import the repository into Vercel. Framework: Vite. Build: `npm run build`. Output: `dist`.

## Before publishing
- Add your actual résumé as `public/resume.pdf` (the current button points there; no résumé is included).
- Add a direct email contact if desired.
- Review experience and project copy for accuracy.
- Recruiter Mode currently shows a shortcut banner; a dedicated condensed content layout is planned for Phase 2.

No production backend is required. Project walkthroughs are illustrative, not live API data.
